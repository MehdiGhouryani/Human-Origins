# Image prompts — read me first

**Purpose.** Self-contained prompts for the class-D images of the Human Origins atlas (portraits, hero scenes, habitats, documented-behaviour scenes). They work in ChatGPT (image generation) or any generator that accepts a long text prompt, and they double as a brief for an artist or 3D modeller.

**What AI may and may not make.**
- Class D only (reconstructions). Never class C (photographs of real specimens, sites, artefacts): a generated image of a fossil would be fabricated evidence.
- Every output is a **draft** until a reviewer signs the checklist below. Publish only with `evidenceClass: reconstruction`, a visible “reconstruction” label, the assumptions list and the reviewer.

**How to use a prompt (ChatGPT or similar).**
1. Open a new conversation for each image (so earlier images do not leak into it).
2. Attach the reference images named in REFERENCE INPUT (rendered or photographed from licensed scans; see classes B and C in the catalog). If you cannot attach them, say so; the prompt still works from the written morphology, but expect lower accuracy.
3. Paste everything inside the box. Ask for **one** image.
4. If the result breaks a rule, reply with the specific failed check and ask for a regeneration. Do not accept “close enough” on a BONE-ANCHORED feature.
5. Save the image and fill the assumptions sheet (below). Upload through the CMS (admin → Media) only after review.

**Project conventions (apply to every prompt).**
- Skin, hair and eye colour are not preserved in fossils. The conventions in each prompt are stated as conventions, never as findings.
- Neutral expression, non-sexualised framing, no racial caricature, no text or watermark in the image.
- Fauna are given as *kinds*; the species must be verified against the site faunal list before publication.

**Assumptions sheet (fill for every published image).**
```text
image code:
generator and version:
date:
prompt file and prompt id:
reference images used (code, licence):
bone-anchored features confirmed visible (list):
conventions applied (list):
deviations from the brief and how they were handled:
regenerated N times, reason:
reviewer, date, decision (approve / revise / reject):
```

**Reviewer checklist.**
1. Every BONE-ANCHORED feature is visible and correct against the reference scans.
2. Nothing under DO NOT INVENT has been rendered as a striking, specific detail.
3. No anachronism (objects, tools, fire, clothing) beyond what the brief lists.
4. Skin, hair, eye colour follow the stated convention; no stereotype.
5. Fauna kinds match the verified site faunal list.
6. The caption says “reconstruction”, names the specimen basis and lists the main uncertainties.
7. Licence and credit fields are complete (the generator’s terms allow this use).
